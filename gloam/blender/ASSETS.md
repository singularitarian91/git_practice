# Gloam — Blender asset spec

All 3D models are generated by Python scripts in this folder using the helpers
in `ghlib.py`. Each `build_<category>.py` script builds one category and
exports `../assets/models/<category>.glb`. `build_all.py` runs them all.

Run with the `bpy` module (`pip install bpy`, Python 3.11) or with Blender:

```
python blender/build_all.py                 # bpy module
blender -b -P blender/build_all.py          # or Blender itself
node tools/preview.mjs out.png assets/models/nature.glb     # render a contact sheet
```

## Art direction

Dark, cozy, Nordic. Think *Valheim* lighting and forms with *Animal Crossing* /
*Stardew Valley* charm: chunky low-poly silhouettes, slightly wobbly
hand-made shapes (use `jitter`), per-face colour variation (`var`), fake baked
AO (on by default in `Builder.build`). Muted, desaturated palette (`ghlib.P`)
with warm amber fire and cold cyan "gloam" magic as the two accent lights.

* Readability first: the default camera sits ~14 m away looking down ~45°.
  Characters are ~1.3–1.7 m tall; make heads, eyes, horns, hats, tools
  chunky enough to read at that distance.
* The game is lit dimly (dusk, torches, fog). Avoid near-black albedo except
  for eyes/pupils/soot; mid-dark tones read best.
* Flat shading is the default and the intended look. `smooth=True` is fine
  for a few round things (mushroom caps, bellies, pumpkins).
* Triangle budgets: small items ≤ 300, crops/props ≤ 800, trees ≤ 900,
  characters ≤ 2 500, buildings ≤ 4 000.

## Technical conventions (the game code relies on these)

* Metres. Z-up in Blender (exporter converts to Y-up). Origin = ground contact
  point at the centre of the footprint unless stated otherwise.
* **Front faces Blender −Y.** (Becomes +Z in three.js.) Doors, counters, faces,
  tool blades all point −Y. A character's left hand is on **+X**.
* Every asset is ONE top-level object in its category file, named exactly as
  listed below (names are the API). Single-part assets can be a single mesh
  object; multi-part assets use an `empty()` root with children.
* Materials: only through `mat=` (`base`, `leaves`, `emit`, `metal`).
  `leaves` = foliage that sways + gets autumn colours. `emit` = glowing
  (flames, eyes, runes, glowing crystals) – it blooms, so keep it small.
* Sockets are empties parented to the relevant part:
  * `hand_r` / `hand_l` – grip point in a character's hand (tools attach here).
  * `light` (or `light_1`, `light_2`…) – where the game spawns a point light /
    flame particles. Put them at flame centres / window centres.
  * `door` – point just outside the entrance at ground level, where the
    player stands to interact.
  * `smoke` – chimney top, for smoke particles.
* Collision metadata as custom properties on the root object (they become
  glTF extras / three.js `userData`):
  * `root["col_r"] = 0.4` – circle collider radius (m), or
  * `root["col_box"] = [w, d]` – axis-aligned box footprint in Blender X/Y (m).
  * Omit both for non-colliding things (flowers, crops, items).
* Keep everything above z = 0 except things that must sink slightly into
  the ground (rock bottoms, stumps, posts: ≤ 0.15 m below).

## Character rig (characters.glb, enemies.glb)

Rigid-part hierarchy animated procedurally in code. Origins **at joints**:

```
<asset>            empty root at the ground, between the feet
└─ body            origin at the hip joint (pelvis centre); torso mesh
   ├─ head         origin at the neck base
   │   └─ (optional ear_l, ear_r, antenna_l, antenna_r, hat …)
   ├─ arm_l        origin at the left shoulder (+X); whole arm incl. hand
   │   └─ hand_l   empty at the grip
   ├─ arm_r        origin at the right shoulder (−X)
   │   └─ hand_r   empty at the grip (held tools attach here, handle
   │               pointing along the forearm, i.e. down when arms hang)
   ├─ leg_l        origin at the left hip joint; leg incl. foot
   ├─ leg_r
   └─ (optional tail, wing_l, wing_r, cloak)
```

Arms hang straight down in the rest pose, legs straight. The procedural
animator rotates parts around their origins (arm swing around X, etc.), so
geometry must not cross the joint in odd ways. Quadrupeds use `body`,
`head`, `leg_fl`, `leg_fr`, `leg_bl`, `leg_br` (+ optional `tail`).

## crops.glb (farm plants; origin at the tile centre; fit within 0.8 × 0.8 m)

* `soil_tilled` – 1 × 1 m tilled patch: slightly raised (≤ 0.06 m) dark soil with 3 furrows; edges bevelled. Colour `soil`.
* `crop_sprout` – stage 1, a pair of tiny leaves (0.12 m). `leaves`.
* `crop_young` – stage 2, small leafy plant (0.25 m). `leaves`.
* `crop_withered` – dead brown drooping plant.
* For each crop id below, two models: `crop_<id>_grow` (stage 3, half-grown, foliage mostly) and `crop_<id>_ripe` (stage 4, harvest-ready, produce visible):
  `turnip` (purple-topped white root poking out of soil), `carrot` (orange shoulders + feathery tops), `onion` (golden bulbs + tall hollow leaves), `barley` (golden grain stalks with heads), `pumpkin` (big ribbed orange pumpkin on vines, ≤ 0.7 m wide), `flax` (slender stalks with pale-blue flowers), `nightshade` (dark purple plant with glossy black-purple berries – tiny `emit` purple glints ok), `beet` (deep red root with red-veined leaves), `frostroot` (winter crop: pale icy-blue crystalline root and white frosted leaves, faint `emit` glow).

## items.glb (inventory icons + dropped items; ~0.25–0.6 m, origin at bottom centre)

Items are shown as icons (rendered in-game from these models, camera looking
from the front-top), so make each one read clearly as a silhouette.

* Materials: `item_wood` (3 split logs tied), `item_stone` (2 stones), `item_flint` (sharp dark flint shard), `item_copper_ore` (ore chunk), `item_iron_ore`, `item_copper_bar` (ingot), `item_iron_bar`, `item_resin` (amber blob, slightly `emit`-free, glossy look via `metal`), `item_fiber` (bundle of plant fibre tied), `item_bone` (crossed bones), `item_gloam_essence` (small glass vial or crystal with swirling cyan glow – `emit`), `item_ember` (glowing coal chunk, `emit` core), `item_leather` (folded hide), `item_feather` (black feather), `item_coal`.

* `item_seeds` – small cloth seed pouch tied with string; the game tints it per crop, so make the pouch **light neutral linen** colour.
* Forage icons reuse nature models (no need to duplicate) except: `item_raspberry` (cluster of berries), `item_blueberry`, `item_hazelnut`, `item_cloudberry` (orange-gold berry).
* Fish (lying on their side, head −Y… any readable pose; ~0.3–0.6 m long): `fish_perch` (green-gold with dark vertical stripes, red fins), `fish_pike` (long, olive with pale spots, duck-bill snout), `fish_eel` (long dark snake-like), `fish_carp` (ghost carp: pale white-blue with faint `emit` fins), `fish_herring` (small silver-blue), `fish_cod` (brown-grey speckled, big head, chin barbel), `fish_mackerel` (blue-green with black wavy stripes), `fish_hagfish` (pinkish-grey eel-like, no fins), `fish_angler` (dark, huge mouth with teeth, glowing lure `emit`), `fish_sovereign` (legendary: large dark fish with gold crown-like dorsal fin and gold eyes).
