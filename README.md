# Hearthmoor

*Working title.* A 3D life-sim / farming game with real combat and open-world exploration —
Stardew's daily loop, Animal Crossing's cozy village, Valheim's dangerous wilderness, and
Breath of the Wild's freedom. Cozy by day, threatening by night.

Built in **Unity 6 (URP)** with Claude Code.
